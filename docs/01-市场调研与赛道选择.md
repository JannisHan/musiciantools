# 01 · 市场调研与赛道选择

> 本文记录从"厄尔尼诺网站"到"乐器工具站"的完整决策链路，含全部证据来源。接手机型只需看结论，证据链接供核验。

## 1. 起点：厄尔尼诺（El Niño）展示网站（已放弃作为首期）

**调研结论（摘要）：**

- **流量特征**：脉冲式/事件驱动。事件爆发期（如 2023-2024 超强厄尔尼诺、2026 年预测潮）搜索量暴涨——2026 年 6 月 El Niño 成为巴西、哥伦比亚 Google 最热搜索话题；中国"超强厄尔尼诺"冲上微博热搜。非事件年份基线很低。
- **头部词竞争**：英文头部词 SERP 被 Wikipedia、Britannica、NOAA（climate.gov）、WMO、USGS 等 DR 90+ 权威站垄断，新站实际无法竞争。
- **机会**：数据可视化/工具形态（SST 异常图、ONI 时间轴）+ 事件驱动时效内容；特朗普政府关停 NOAA 气候数据站后存在权威真空（NPR 2026-06 报道）。
- **放弃原因**：用户方向转为"出海独立工具站"，且希望做自己熟悉的领域。

**反面教训：**
- 通用工具站（300 工具）流量主要不来自 Google，而来自书签/社交——[DEV.to 复盘](https://dev.to/alberto_miller_f44a8880a3/i-built-300-free-web-tools-at-18-heres-what-actually-drove-traffic-hint-not-google-5gei)。**结论：必须做垂直（有人搜的词），不能做通用大杂烩。**
- AI Overviews 吃掉了"纯查询/纯计算"类最简单流量（[AI ate the niches first](https://kubaik.github.io/ai-ate-the-niches-first/)）。**结论：做"AI 一句话替代不了"的工具（交互式、需要操作、安全决策类）。**

## 3. 行业选型过程

**用户知识领域**：网络运维、Windows/Linux 系统运维、健身、吉他。

**候选垂直的调研结论：**

| 垂直 | 结论 |
|---|---|
| 农业/园艺 | 有需求但用户零认知，弃 |
| 建筑/装修 DIY | 同上，弃 |
| 宠物 | SERP 已被 7+ 工具站覆盖，饱和，弃 |
| 网络/系统运维 | ✅ 机会好：chmod/umask 计算器前排是个人站和作业站、IPv6 子网计算器前排是弱站、crontab.guru 验证需求；**作为二期/辅站** |
| 健身 | 网页端杠铃片计算器无权威站；**作为三期备选** |
| **吉他 → 乐器全行业** | ✅ **选定首期**：弱 SERP 密集（见下）、传播属性好（乐手社区爱分享）、联盟佣金高（乐器客单价高） |

**选乐器的核心理由：**
1. 乐手社区（Reddit r/Guitar、The Gear Page、Seymour Duncan 论坛等）可用于需求验证、产品反馈与推荐流量；社区链接不预先计作稳定 SEO 外链；
2. 换弦、调弦和设备配置天然接近商品决策，具备联盟验证空间；实际项目准入、地区、归因和佣金以获批后的官方条款为准；
3. 四类互不重叠的搜索人群：家长（选尺寸）、学生（转调/乐理）、玩家（setup/护理）、制作人（BPM/采样）；
4. 用户本人懂吉他 → 内容质量优势（E-E-A-T）。

## 4. 乐器行业工具格局调研（2026 年实况）

> 本节是早期赛道筛选快照，不能继续作为开发排序依据。2026-08-30 对首批五个词的最新 SERP、竞品与页面边界核验见 `05-关键词SERP与MVP裁决.md`；最新核验显示品丝、BPM 和张力方向均有成熟直接竞品。

| 品类 | 现有玩家 | SERP 实况 | 机会判断 |
|---|---|---|---|
| 转调计算器（Bb/Eb/F 管乐） | CMUSE、通用计算器站 | 弱：通用站霸榜，无专业工具站 | 有机会 |
| 品丝位置计算器 | 90 年代老站 ekips.org | 弱：老站霸榜至今 | ✅ 强机会 |
| 延迟时间计算器（BPM→ms） | 个人吉他博客 | 弱 | ✅ 强机会 |
| 琴弦张力计算器 | 丹麦语站、PyPI 包、App | 网页无强者 | ✅ 可做 |
| 弦乐器尺寸选择 | 琴行文章（fiddlershop） | 工具形式空档 | 有机会 |
| 乐器存放湿度 | 仅论坛讨论 + 硬件产品 | 工具真空 | 蓝海（后期做） |
| 制作类（BPM/key 检测） | Soundplate、ABYZOR 合集 | 单工具词未满 | 长尾可做 |
| 和弦/音阶查找 | App 生态强（smartChord） | 网页端机会有限 | 慎入 |
| 五度圈/音程 | 有玩家 | 中 | 长尾可做 |

**重要发现：CMUSE（cmuse.org）正在批量产出"音乐计算器"内容（69 页分类）**——它验证了这个方向的需求，但它是内容站（文章里嵌简易计算器），**工具站的差异化就是交互体验比它好一个量级**。

## 5. 最终决策摘要

1. 首期做**乐器工具站**，但产品切口收窄为吉他设置与设备规划；
2. 先发布 BPM/延迟工具验证 SEO，同时准备琴弦张力比较器验证产品和联盟意图；不预设批量铺页；
3. 变现先验证与计算结果相关的乐器联盟点击，AdSense 在有稳定流量且满足同意管理要求后再评估；
4. IT/运维工具站为二期项目（已验证弱 SERP，词量预期更大），健身为三期备选。
