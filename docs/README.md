## 项目一句话定位

一个面向**海外市场**的乐器行业垂直工具站。首期聚焦吉他手的设置与设备规划，用可信计算、配置对比和可分享结果解决换弦、改调弦与延迟设置问题；自然搜索是获客渠道，不是产品定义。

- **品牌名**：Musician Tools
- **域名**：`musiciantools.app`（已定，见 `03-品牌与域名决策.md`）
- **目标市场**：首发只面向 US English；多语言须根据真实查询数据另行立项
- **变现模式**：BPM/Delay MVP 不变现；先验证搜索曝光与真实工具使用，再评估与用户任务相关的商业模式

## 已确定的决策（不可随意推翻，如有异议请先给出数据依据）

1. 赛道 = 出海乐器行业工具站（放弃国内，放弃厄尔尼诺站，放弃 IT/运维站作为首期）
2. 玩法 = 先验证双工具 MVP，再依据 GSC 查询、产品使用和联盟点击扩展；不预设批量铺 20+ 页面
3. 首批开发 = 只发布 BPM/延迟工具验证搜索获客；琴弦张力比较器在数据使用边界和可追溯数据集确认后进入 P1
4. 域名 = `musiciantools.app`（musictools.app 已被占用，勿再纠结）
5. 技术形态 = TanStack Start + Cloudflare Workers/Static Assets；公开路由预渲染，计算留在客户端，Worker 只做 SSR 回退和匿名事件接收

## 关键约束提醒

- **诚实预期**：当前五个重新核验词的需求基线约 3,750 次/月，查询量不等于本站访问量。新站增长周期不设固定“沙盒期”，首年先验证非品牌曝光、工具完成率、分享率和联盟点击，再用真实数据建立预测。
- **不碰灰色**：不做下载器类、不做版权内容，只做工具。
- **知识正确性**：所有公式、数据（品丝常数、琴弦规格、单块耗电）必须来自公开可靠来源并在页面标注来源，避免 E-E-A-T 失分。
