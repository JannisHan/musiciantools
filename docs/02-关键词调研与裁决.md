## 2. 数据解读原则（必须遵守，否则会误判）

1. **"0 搜索量" ≠ 没人搜**：Semrush 不追踪极小量词。`speaker impedance calculator` 显示 0/9，但其变体（`speaker ohm calculator`、`8 ohm 4 ohm parallel`、`guitar cab impedance` 等）加起来可观，且这类词在论坛传播价值高。
2. **KD=0 ≠ 最好做**：Semrush 的 KD 0 表示"数据不足、无法计算"，不是"零难度"。KD 0 的词需以 SERP 实况判断——本清单中 KD 0 的词前排均为弱站（个人博客/老站/通用计算器站），判定为可做，但勿被"0"误导。
3. **必须保留数据口径**：Semrush 搜索量需要同时记录国家、设备、日期、趋势与 SERP 快照。未保存口径的数据只能用于方向判断，不能直接进入流量预测。
4. **KD 不是产品优先级**：开发顺序同时考虑搜索需求、真实 SERP、用户任务、差异化、开发/数据风险和商业价值。禁止再使用固定的“量/KD 阈值”自动裁决工具。

## 3. 逐词裁决

| 关键词 | 量/KD | 裁决 | 理由 |
|---|---|---|---|
| guitar string tension calculator | 1900/31 | ✅ MVP 商业核心 | 已核验词中需求最大，且与换弦/选弦购买行为直接相关。虽然竞争高于其他词，但应通过“当前配置 vs 目标配置”的对比体验和可信厂商数据建立差异化，而不是因 KD 31 排后 |
| hz to note（含 note frequency / midi / cents 变体） | 590+50+0+0 / 23 | ⏸️ P2 候选 | 与首期吉他设置定位和商品决策距离较远，且现有竞品已覆盖四向转换；首发验证完成后重新研究 |
| bpm to ms + delay time calculator | 1000/3 + 480/20 | ✅ MVP 获客核心 | 两词共享 BPM 输入、ms 换算和音符细分结果，应合并为一个页面。`bpm to ms` 是低 KD 锚点，但不能把 KD 3 外推到整个延迟词族 |
| fret calculator + fret spacing calculator | 260/9 + 110/6 | 🔶 P1 候选 | 两词意图高度重合，应合并为一个页面。低 KD 值得测试，但总需求仅占已核验词约 9.9%；只有加入等比例 SVG/PDF、打印校准或 multiscale 等制琴能力时才有产品差异化 |

| speaker impedance calculator | 9/0 | ⏸️ P2/专家审核后 | 涉及设备安全且搜索需求尚未充分核验，不以“外链磁铁”名义提前开发 |

## 4. 集群策略（本项目流量模型的核心）

**原则**：一个工具页面覆盖一个词族，而不是一词一页。

| 工具（页面） | 覆盖词族 | 合计预估量（月） |
|---|---|---|
| BPM/延迟工具 | bpm to ms、ms to bpm、delay time calculator、dotted eighth note delay、tempo to milliseconds；同一页面覆盖，不拆分 | **已核验 1,480**（仅 `bpm to ms` + `delay time calculator`） |
| Hz↔音符↔MIDI↔音分 | hz to note、note frequency calculator、midi note number converter、cents to hz、note to midi、frequency to note | ~1,000+ |
| 琴弦张力计算器 | guitar string tension calculator、bass string tension、string gauge tension、各调弦变体；首版只承诺已验证词 | **已核验 1,900** |
| 品丝计算器 | fret calculator、fret spacing calculator；其他乐器变体先作为预设，不提前拆页 | **已核验 370** |
| 音频文件大小 | audio file size calculator、wav file size、mp3 size calculator | ~300+ |
| 阻抗计算器 | speaker impedance calculator、speaker ohm calculator、cab impedance、8 ohm 4 ohm parallel | 变体不可测，价值在外链 |
| 电源计算器 | pedalboard power calculator、pedal power draw、pedal mA | 变体不可测，价值在外链 |

**当前可审计需求基线**：五个重新核验词合计约 3,750 次/月。该数字是查询需求，不等于本站可获得的访问量。首年不预设 5k-15k 月访问；先用 GSC 记录非品牌曝光、进入前 20 的查询数、点击率与页面使用行为，再根据真实排名建立预测模型。

## 5. 上线后持续挖词方法

1. 在 Semrush/Ahrefs 输入已上线工具词 → 保存国家/设备/日期/趋势和相关关键词导出 → 人工检查搜索意图与 SERP，再决定建页、并入现有工具或不做；
2. 监控 Google Search Console 已有点击的真实词 → 放大成功词族；
3. 西语/葡语版必须先分别完成当地关键词与联盟可用性验证；不能假设直接翻译会自动放大流量。

## 6. 判定框架（全项目通用）

每个候选工具从以下六项评分并保留证据，不再使用固定 KD 阈值：

1. **用户价值**：是否解决一个明确且需要操作的任务；
2. **搜索机会**：需求、趋势、SERP 形态和 URL 级竞品强度；
3. **商业距离**：结果是否自然影响商品或服务选择；
4. **差异化**：是否拥有对比、导出、可视化、数据库或工作流优势；
5. **交付风险**：公式、数据许可、维护和安全责任；
6. **集群一致性**：是否服务首期目标用户，并能与已有工具形成自然内链和复访路径。

当前首发裁决：**琴弦张力比较器负责验证产品与商业价值，BPM/延迟工具负责验证低成本搜索获客；品丝工具作为 P1 候选。**
